About this book

Applied Calculus Using R and Python — Abraham Ayebo

Applied Mathematics · Volume II. Online preview, November 2026.

Purpose

This textbook combines single-variable calculus, mathematical reasoning, computational exploration and real-world modeling. Ten chapters and two programming appendices support analytical work with R and Python.

Using the online edition

Read chapters in order or use the search box. Explore the interactive investigations, then use the downloadable code to reproduce and extend the computational laboratories. Mathematical typesetting requires an internet connection.
